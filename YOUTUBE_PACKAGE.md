## 6. How to Upload to YouTube

### Method A: YouTube Studio Web UI (Easiest)
1. Go to [https://studio.youtube.com](https://studio.youtube.com).
2. Click **Create** (top right) ➔ **Upload videos**.
3. Select your `.mp4` recording.
4. Copy-paste the **Title**, **Description**, and **Tags** from Sections 1, 2, and 3 above.
5. Set Visibility to **Public** (or **Unlisted** if submitting privately for judging).
6. Click **Publish**.

### Method B: Automated Python Script (API v3)
Use the included automated upload tool:
```bash
# 1. Install dependencies
pip install google-api-python-client google-auth-oauthlib google-auth-httplib2

# 2. Place your 'client_secrets.json' from Google Cloud Console in the project root

# 3. Run the uploader
python scripts/upload_to_youtube.py --file "C:/path/to/your/demo_video.mp4" --privacy public
```
